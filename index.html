1. Firestore + Persistent Local Vault Status

Firestore Security Rules Notice (Data is safely stored in your local vault)

Your Firebase project (siyanat-housekeeping) returned a permission error on one or more collections. Your data is safe in persistent local storage, but to allow cloud sync across devices, go to Firebase Console → Firestore Database → Rules and publish:

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /{document=**} { allow read, write: if request.auth != null; } } }

How to get your fm.marol Google Drive Web App URL (1-Time Setup)
  1. Sign in to script.google.com using your fm.marol@jameasaifiyah.edu Google account and click New Project.
  2. Click Copy Apps Script Code above, paste it into Code.gs (replacing existing code), and click Save ().
  3. Click Deploy → New deployment, choose type Web app, set Execute as: Me (fm.marol@jameasaifiyah.edu), and Who has access: Anyone.
  4. Copy the generated Web app URL, paste it in the box above, and click Save Drive Configuration.
